1. Extract this zip.
2. On github.com make a new repository, click "Add file > Upload files",
   and drag in EVERYTHING inside this folder (including the hidden .github folder and src folder).
3. Extract the Forge 1.8.9 MDK zip and upload these items from it to the same repo:
   build.gradle, gradlew, gradlew.bat, and the gradle folder.
   Do NOT upload its src folder.
4. Open the Actions tab. When the run finishes, download "bridgetrainer-jar" at the bottom.
